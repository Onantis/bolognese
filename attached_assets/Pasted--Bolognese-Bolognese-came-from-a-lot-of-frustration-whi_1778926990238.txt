# Bolognese

Bolognese came from a lot of frustration while building projects and losing time over small syntax mistakes, broken imports, invalid declarations, and random parser errors that were harder to track than they should have been.

I tried different tools over time, but most of them focused mainly on formatting or style rules. What I wanted was something more focused on actually understanding when code is broken, why it breaks, and how some of those issues could be resolved automatically instead of stopping the entire workflow.

So Bolognese was built around that idea.

The package analyzes JavaScript and TypeScript code, detects syntax and structural problems, and reports issues in a way that is meant to stay practical instead of noisy. For supported cases, it can also apply fixes automatically.

The goal is not to replace every existing linter or formatter. Bolognese is mainly focused on diagnostics, validation, recovery, and making codebases easier to maintain when things start failing unexpectedly.

It is designed to work both in small personal projects and larger environments like CI pipelines, editor integrations, build systems, and automated workflows.

The overall approach is simple:

* detect problems early
* keep reports readable
* avoid unnecessary complexity
* make fixes predictable
* stay lightweight enough to integrate anywhere

That is the direction the project is built around.

## Vision

Bolognese aims to provide a lightweight and extensible analysis engine for source code validation and correction.

The project focuses on:

* Syntax validation
* Error detection
* Structural analysis
* Automated issue resolution
* Developer tooling integration
* Fast execution performance
* Configurable analysis rules

# Core Features

## Syntax Detection

Detects:

* Missing brackets
* Invalid tokens
* Unexpected expressions
* Unclosed strings
* Invalid imports
* Invalid declarations
* Parser failures

## Structural Analysis

Analyzes:

* Unused variables
* Duplicate declarations
* Invalid scopes
* Unsafe patterns
* Formatting inconsistencies
* Unsupported syntax usage

## Automated Resolution

Provides optional automated fixes for:

* Formatting problems
* Missing semicolons
* Import ordering
* Basic syntax corrections
* Whitespace normalization
* Consistent indentation

## CLI Support

Includes command-line tools for:

* File scanning
* Recursive project analysis
* JSON output
* CI integration
* Automatic fixing
* Rule configuration

# Example Usage

## Installation

```bash
npm install bolognese
```

## Basic Usage

```js
import { analyze } from "bolognese";

const result = analyze(`
function test( {
  console.log("Hello")
}
`);

console.log(result);
```

## Auto Fix

```js
import { fix } from "bolognese";

const output = fix(sourceCode);

console.log(output.code);
```

## CLI

```bash
bolognese scan src
```

```bash
bolognese fix src
```

# Suggested API

## analyze()

Analyzes source code and returns detected issues.

```ts
analyze(code: string): AnalysisResult
```

## fix()

Applies automatic fixes where available.

```ts
fix(code: string): FixResult
```

## configure()

Loads custom rule configuration.

```ts
configure(options: ConfigOptions): void
```
